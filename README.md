# genbus885-final-moyers_d
Overview

This project analyzes sales performance for RUSH using three related datasets:

Sales
Products
Retailers

The datasets were cleaned, validated, and merged into a single dataset to provide meaningful business and marketing insights.

Objectives:
Answer business questions posed by leadership and provide other insights to improve marketing efficiency

Data Sources:
RUSH's sales, products, and retailers tables. They are uploaded in the notebook via GitHub url's

Run Source:
This is a Jupyter Notebook created in Google Colab. It runs in Python.

Findings:
Areas of success are clear. Both men’s and women’s products sell the most in the North East in the late summer months - with a focus on men’s streetwear shoes and items that cost around $50 after a 30-40% markup.
